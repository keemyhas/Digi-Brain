# Workflow: Memory Consolidation & Retrospective

## 1. When used

End of milestones, periodic cycles, or when memory gets bloated/contradictory.

## 2. Relevant agents

`memory-manager` (lead), `orchestrator`, `codebase-researcher`

## 3. Execution sequence

1. **Verify against code** — memory files vs active repository; code wins conflicts. 2. **Dedup & clarify** — merge duplicates, resolve stale assumptions, unify terminology. 3. **Distill lessons** — only durable, high-value principles survive. 4. **Archive** — milestone summary to `session-summaries.md`. 5. **Report** — updates, trends, recommendations to the owner.
